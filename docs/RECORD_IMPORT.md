# 解析记录导入

进入目标域名的 **解析记录 → 批量操作 → 导入记录**。选择文件来源（通常用“自动识别”）和导出文件，先检查预览中的记录值、线路、TTL、错误及跳过数量，再点击“确认添加”。文件在浏览器内解析；确认后才逐条调用现有的添加解析接口。导入只新增记录，不覆盖或删除现有记录。

## 支持格式

| 格式 | 常见来源 | 要求 |
| --- | --- | --- |
| `.xlsx`、`.xls` | 彩虹 DNS、阿里云、腾讯云、华为云及其他表格导出 | 首个工作表有表头 |
| `.csv`、`.tsv`、`.txt` | DNS 服务商表格导出 | 表头含主机记录、记录类型、记录值；支持逗号、制表符、分号、竖线分隔及双引号引用 |
| `.txt`、`.zone` | Cloudflare、BIND Zone | 标准 `$ORIGIN`、`$TTL`、`IN` 记录写法；根域名 NS/SOA 会跳过 |
| `.json` | Cloudflare API、阿里云/腾讯云/华为云记录列表 | 记录数组或常见 `result`、`RecordList`、`DomainRecords.Record`、`recordsets` 包装 |

可识别的表头包括 `主机记录` / `Name` / `SubDomain` / `RR`、`记录类型` / `Type`、`记录值` / `Value` / `Content` / `Records`，以及线路、TTL、权重、MX 优先级、备注、状态等常见别名。没有清晰表头的厂商自定义 TXT 文件，请整理为如下 UTF-8 CSV：

```csv
主机记录,记录类型,线路类型,记录值,TTL
@,A,默认,192.0.2.10,600
www,CNAME,默认,example.com,600
_acme-challenge,TXT,默认,"example-verification-token",600
```

域名列可以填写 `@`、相对主机名或当前域名下的完整域名。带点的多级主机名请写成当前域名下的完整域名。文件中其他域名的记录会标记为错误，不会写入。MX 可使用单独的 `MX` / `Priority` 列，也可使用彩虹 DNS 导出的 `服务器地址 | 优先级` 形式。

## 线路与状态

来源线路名称和常见线路代码会转换为目标 DNS 服务商的可用线路。例如腾讯云、阿里云和华为云的电信/联通/移动名称会对应到目标服务商的同名线路。未匹配的线路使用目标默认线路，预览中会显示 `原线路 → 默认线路`；请在确认前核对。对于无法自动判断的数值线路代码，可以手动选择文件来源后重新解析。

源记录已暂停时会显示在预览中并跳过，防止在目标服务商上意外启用。Cloudflare 的 `proxied` 状态仅在目标服务商也是 Cloudflare 且记录类型支持代理时保留。导入不迁移服务商专有设置，例如 DNSSEC、地理规则、负载均衡或代理策略。记录类型必须受目标服务商支持；服务商 API 的拒绝原因会显示在对应记录的结果列。

单文件上限 5 MB、5000 条记录。建议按域名分别导出和导入，先确认来源文件属于当前选中的域名。
